# 隐私与复用边界

模板只包含通用程序、配置、制作流程、虚构示例和默认图标。每门课程先创建独立工程，放在`local/projects/`或另一个私有目录，避免把真实知识资料写回模板。

## 本地数据去向

| 数据 | 默认位置 | 处理方式 |
| --- | --- | --- |
| 原笔记、教材、提取结果、核查记录 | 项目`.local/` | 本地私有，原文件不修改 |
| 生成课程及学习所需图片 | 独立课程项目 | 由课程制作者决定交付范围 |
| 学习记录 | 浏览器或Android WebView本地存储 | 使用App备份导出；不自动云同步 |
| 签名与密码 | 项目`.signing/` | 私下备份，不放入源码发布集 |
| APK与验证报告 | 项目`output/` | 默认不加入模板发布集 |

本地预览仅绑定回环地址，只服务运行文件和课程明确引用的图片；不公开原文件、配置、密钥和核查记录。它没有用户登录或网络共享模式。

套件不调用AI或OCR服务。使用外部助手可能使资料进入该助手的处理环境；制作前说明需要发送的文件和去向。离线学习不代表所有外部制作工具都在本地运行。

## 上传集检查

使用显式文件清单检查实际要上传的内容，拒绝未列明文件、危险路径、密钥、个人路径、联系信息和文本型图片元数据。私人词表在仓库外提供，避免把敏感内容写进扫描器本身。自动检测有范围限制，还需人工审查图片、措辞、文件名和上下文。

新仓库从检查过的干净文件集建立，不复制旧工程Git历史。公开署名、隐藏邮箱、提交说明、Issue、日志、附件与截图都在发布检查范围内；不修改使用者的个人资料页。账号与默认图标的公开关联由仓库所有者决定。

## 默认图标与许可

默认黑猫图标为直接接入的现有PNG，无编号，不重新绘制。文件名为通用`app-icon.png`；不保留来源中的私人别名。检查到的PNG只有图像、色彩配置等数据块，没有文本说明块。

代码、图标和第三方依赖分别核对复用范围。`DISTRIBUTION.json`记录尚未选择的许可和公开分发事项；本地整理不代替权利确认。确定代码许可后保留适用的原始许可与署名，默认图标另说明是否可在派生软件中继续使用。不得把模板的许可套到用户导入的教材或其他图片上。

当前为公开模板。仓库中只包含已检查的通用内容；代码和默认图标的复用许可状态分别记录在`DISTRIBUTION.json`中。
